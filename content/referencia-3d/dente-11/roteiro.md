## Fase 02 — Terços (~11 mm)

| | |
|--|--|
| **Arquivo de vídeo** | `fases/02-tercos.mp4` |
| **Frames** | `frames/02-antes.jpg` · `02-durante.jpg` · `02-depois.jpg` |
| **O que acontece** | Divide a altura (~34 mm) em três terços iguais (~11 mm) com linhas que cercam o perímetro. |
| **Face principal** | Começa na vestibular e contorna todo o bloco (anéis completos) |
| **Instrumento** | Lecron afiado + régua milimetrada |
| **Direção do movimento** | Traçado transversal horizontal, circunferencial — ponta do Lecron raspa linha rasa contínua até fechar o anel |
| **Material a destacar no 3D** | Duas linhas (limite cervical–médio e médio–incisal); sem remoção de volume |
| **Resultado esperado** | Três segmentos iguais; linhas se encontram nas arestas; guia para bossa, fossa e cíngulo |
| **Erro comum** | Terços desiguais; linhas só em uma face (não fecham o perímetro) |
| **Notas para o 3D** | Linhas azuis pulsantes. Seta acompanhando o traçado ao redor. Bloco ainda intacto em volume. |

| **O que acontece** | Em vista mesial, desenha contorno vestibular e lingual nos terços; transfere em paralelo para a distal. |
| **Face principal** | Proximal mesial → depois distal |
| **Instrumento** | Lecron afiado |

| **Erro comum** | Transferência sem paralelismo → assimetria mesial/distal |
| **Notas para o 3D** | Câmera em vista proximal. Overlay das linhas V/L. Sem corte ainda — só desenho. |

## Fase 04 — 1ª sequência: cervical + redução grosseira

| | |
|--|--|
| **Arquivo de vídeo** | `fases/04-primeiro-corte.mp4` |
| **Frames** | `frames/04-antes.jpg` · `04-durante.jpg` · `04-depois.jpg` |
| **O que acontece** | Aprofunda o limite cervical; remove excesso fora do perfil proximal (MD e inciso-cervical); inicia concavidade lingual. |
| **Face principal** | Proximais e depois lingual (terços médio-incisais) |
| **Instrumento** | Lecron afiado (cervical e redução); Lecron de fábrica (início da fossa lingual) |
| **Direção do movimento** | 1) Aprofundar colo (movimento horizontal controlado). 2) Redução MD paralela às linhas. 3) Redução inciso-cervical fora do desenho. 4) Raspar fino perto das linhas. 5) Na lingual, movimento côncavo com Lecron de fábrica |
| **Material a remover (rosa no 3D)** | Todo volume externo às linhas proximais V/L |
| **Resultado esperado** | Silhueta grossa de coroa; compare com gesso em distal e proximal |
| **Erro comum** | Corte profundo logo nas linhas (ultrapassa o desenho); lascar a base por não aprofundar o cervical antes |
| **Notas para o 3D** | Morph forte bloco→forma grossa. Ghost rosa do excesso. Seta MD e inciso-cervical. Continua do estado da fase 03. |

| **Direção do movimento** | Espátula: desgaste côncavo entre futuras cristas marginais. Lecron no cíngulo: inclinação ~45° para lingual. Incisal: arredondar mesial; suavizar distal |

| **Resultado esperado** | Fossa definida sem invadir o cervical; cíngulo projetado e inclinado; ângulos incisais diferenciados |
| **Erro comum** | Aprofundar fossa no terço cervical (invade o cíngulo); cíngulo sem inclinação |
| **Notas para o 3D** | Vista lingual. Ghost na fossa. Seta a 45° no cíngulo. Destacar ângulo mesio-incisal vs disto-incisal. |
