# Estilo-guia obrigatório das imagens de fase

Referência ouro: `padrao-oclusal-16.png` (imagem enviada pela Gabriela — FDI 16 oclusal).

## Elementos fixos
1. Fundo azul-claro limpo, luz de estúdio suave
2. Modelo de cera/resina **marfim fotorealista** (aspecto de modelo físico)
3. Badge navy circular com ícone + `FACE EM TRABALHO: {FACE}`
4. Barra/título navy com texto amarelo/branco
5. Verde = preservar · Vermelho = remover + legenda canto inferior direito
6. Instrumento metálico realista (Lecron) tocando a área ativa
7. Sem mãos, sem watermark, sem visual cartoon/CGI plástico

## Uso no app
- PNG em `public/images/tooth-{FDI}/fase-XX.png`
- Alta resolução 3072×2048 (`npm run phase-images:hires`)
